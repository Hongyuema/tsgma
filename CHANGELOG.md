# Release history

## 1.1.0 — 25 November 2026

- Release the frozen numerical data, all reference tables, eligibility records and the complete period search.
- Add a data dictionary, source attributions, component licence notices and SHA-256 checksums.
- Add `--analysis-only` to rebuild the numerical results without publication artwork.
- Read lossless CSV exports of historical plotted observations when native Prism projects are unavailable.
- Archive data and code together in Zenodo.

The statistical estimators, primary specification and reported grades are unchanged from version 1.0.0.

## 1.0.0 — 25 November 2026

Initial public code release, including analytical scripts, synthetic example, independent estimator tests and the full-archive reproduction runner.
