# Development provenance

The analysis implements the TSGMA specification developed for the accompanying manuscript by Hongyue Ma. Source reconciliation, eligibility rules and exploratory choices are documented with the study materials.

OpenAI Codex assisted with code preparation, documentation, formatting and verification. The verification record describes the checks actually executed; it is not a claim of independent replication or an assurance that all modelling assumptions hold. Scientific interpretation and responsibility remain with the author.

The public repository excludes conversation records, local workstation paths, manuscript drafts, credentials and third-party artwork. Changes to the statistical specification should be documented separately from formatting and documentation changes.
